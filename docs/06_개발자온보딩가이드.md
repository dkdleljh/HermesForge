# 개발자 온보딩 가이드

## 사전 준비
- Python 3.12+
- Node.js 20+

## 로컬 개발
1. 루트에서 가상환경 생성
2. `pip install -r backend/requirements.txt`
3. `cd frontend && npm install`

## 백엔드 구조
- `app/services`: 유스케이스
- `app/engine`: 핵심 알고리즘
- `app/repositories`: 저장소 인터페이스/구현
- `app/plugins`: 도메인 모듈

## 프론트 구조
- `pages`: 화면 단위
- `services`: API 통신
- `types`: 타입 모델

## 코딩 원칙
- 타입 힌트 필수
- 정책 우회 금지
- 문서/코드 동기화 유지
