# 프로그램 사용 설명서

## 처음 실행
1. `scripts/setup_dev.sh`
2. `scripts/run_backend.sh`
3. `scripts/run_frontend.sh`

## 화면별 사용 방법
- 대시보드: 전체 지표와 최근 렌더 확인
- Evidence: evidence 추가/조회/상세 확인
- Patch: patch 생성/조회
- Snapshot: 생성/목록/병합
- Materialize: context 입력 후 렌더 실행
- Demo: 교육/게임/훈련 시드 주입

## 시뮬레이션 실행 방법
1. Demo에서 bootstrap 실행
2. Snapshot 화면에서 snapshot 선택
3. Materialize에서 컨텍스트 변경 후 반복 실행

## Snapshot 생성 방법
- `snapshot 생성` 버튼 또는 `POST /api/snapshots/generate`

## Context 변경 방법
- role/environment/scenario_profile/intent를 변경
- 같은 snapshot이라도 출력이 달라질 수 있음

## 결과 해석
- 출력 배지: `POSSIBILITY_RENDER`, `NOT_FACT`
- 사실 기록이 아님

## 자주 발생하는 문제
- API 연결 실패: 백엔드 실행 확인
- 렌더 실패: snapshot_id 누락 여부 확인
