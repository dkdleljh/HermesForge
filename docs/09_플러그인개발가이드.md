# 플러그인 개발 가이드

## 목표
코어 엔진 수정 없이 새 도메인 시뮬레이션 모듈을 추가한다.

## 필요한 인터페이스
- `DomainPlugin.name`
- `sample_evidence()`
- `context_hint()`

## 구현 절차
1. `backend/app/plugins/new_domain.py` 생성
2. `DomainPlugin` 구현
3. `registry.py`에 등록
4. bootstrap 실행으로 동작 확인

## 샘플 구현 포인트
- evidence payload에 `category`, `suggested_outcome`, `message` 포함
- context_hint에 role/environment/profile/intent 제공

## 주의사항
- 위험 category(harmful/illegal) 결과는 정책에 의해 차단됨
- 출력은 항상 사실이 아님을 전제로 설계
