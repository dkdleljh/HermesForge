# 테스트 가이드

## 단위 테스트
- materialize: 컨텍스트 반영 여부
- merge: forbidden category 제거
- safety policy: label/watermark 강제
- evidence ingest: API 입력 검증

- snapshot generate → materialize 흐름

## 시나리오 테스트
